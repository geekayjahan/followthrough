# Followthrough

## Setup

This is a connected v0 under construction. All ten Core features remain in scope. The initial runtime is a local Node.js 24 process with one SQLite database and a responsive web page. No app hosting or Daytona provisioning is implied by these files.

1. Install Node.js 24. The app uses built-in HTTP, fetch and SQLite; the only pinned runtime dependency is ffmpeg-static 5.3.0 for local voice conversion. After the coder supplies package.json, run `npm.cmd --prefix app install`.
2. Configure `app/.env` in this checkout. An empty template has been prepared when no file existed. Keep credentials only there; do not paste them into chat or commit them. Set a strong `OWNER_PASSWORD`, keep `APP_LIVE=false`, and keep the app URL consistent with the browser origin.
3. Supply the fresh Zoho account OAuth credentials, matching region, Mail account/from address, Books organization, expense account, cash account and stall customer IDs. Map each sale lot to its fresh Books `books_item_id` in the synthetic dataset. Existing business accounts and real customer records are outside this build's data boundary.
4. Configure up to five verified WhatsApp test numbers, identify owner numbers within that list, and supply the Cloud API phone number ID, token, webhook verify token, app secret and the Graph API version enabled for that app. Configure an approved brief template/language for delivery outside the messaging window. A public HTTPS webhook route still needs an owner-selected host or explicitly authorized tunnel.
5. Supply the actual Meta open-weights model endpoint and model name from the owner-managed Daytona sandbox. Supply its API key if required. Set the Meta Voice key and an optional `FFMPEG_PATH` override if needed. The pinned ffmpeg-static package supplies the binary for WhatsApp OGG-to-WAV conversion. No model ID or working access is assumed.
6. Supply or approve `app/data/synthetic.json`. Any included starter is illustrative synthetic data, not owner-provided data or connected proof. Every dataset email must end in `@example.test`; WhatsApp numbers must be null or on the configured test list. Review/map records before connecting.
7. After source implementation lands, run `npm.cmd --prefix app start` from the repository root and open the configured `APP_URL`. The planned local default is `http://127.0.0.1:4310`. Run `npm.cmd --prefix app test` for isolated checks once supplied by the coder. These are the shared command contract, not an initialization-time execution claim.

Missing credentials block their provider operations and connected checks; source implementation can continue while the owner configures them. The UI must show unavailable/stale integrations rather than invented zero balances or fixture totals. Do not enable scheduled brief delivery until recipients, messaging-window/template rules and explicit owner authorization are confirmed. The process must stay running for the two London brief slots; initial local operation cannot prove always-on hosting.

External sends and Books writes require explicit owner approval tied to the pending action. Build and test commands must not silently perform them. Keep `ENABLE_JOBS=false` and `ENABLE_POLLING=false` until the owner intentionally enables scheduled delivery and background ingestion. Opening the page or starting the server does not enable either. Never treat a local test, fixture or queued request as evidence that a message arrived or a Books record exists.

The shared architecture and interface contract is in `app/app-spec.json`; the canonical product scope is `app/spec.html` and the connected acceptance bar is `app/evals.md`. Instagram access, model hosting/access, public app hosting, owner dataset/recipient details and chase parking policy remain explicit open decisions. The official Instagram Business Discovery adapter uses optional `INSTAGRAM_USER_ID` and `INSTAGRAM_ACCESS_TOKEN`; owner-verified professional-account permissions are required. A configured profile without that access is incomplete qualification. No Instagram scraping is implemented or authorized by this foundation.
